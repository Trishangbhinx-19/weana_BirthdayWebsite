# Weanna Birthday Website 🖤

A simple interactive birthday website made by Shang for Weanna.

## How to open it

Double-click `index.html` or open it with VS Code + Live Server.

## Add your music

1. Put an MP3 file inside the `music` folder.
2. Rename it to:
   `birthday-song.mp3`
3. Refresh the website.

## Add permanent photos

The website currently lets you preview photos directly in the browser.

For the online version, create an `images` folder and put your photos there.
Then replace the photo placeholders in `index.html` with image paths such as:

<img src="images/weanna1.jpg" alt="Memory 1">

## Publish it

You can upload the entire folder to a GitHub repository and enable GitHub Pages.
Then send the resulting link to Weanna.
